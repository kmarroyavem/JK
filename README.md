# Nuestra historia — 10 años ♡

Página estática, responsive y lista para GitHub Pages.

## Publicar
1. Crea un repositorio en GitHub (por ejemplo `nuestros-10-anos`).
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets` (mantén las rutas).
3. En **Settings → Pages → Build and deployment**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. GitHub mostrará el enlace publicado en Pages.

## Fotos
Coloca en `assets` estas imágenes (JPG):
- `portada.jpg`
- `viaje-1.jpg`
- `viaje-2.jpg`
- `estudios.jpg`
- `graduacion.jpg`
- `familia.jpg`
- `recuerdo.jpg`

Para añadir o cambiar fotografías, edita la lista `photos` en `script.js`. Optimiza las fotos antes de subirlas (idealmente 150–400 KB por foto). Las imágenes faltantes muestran un marcador temporal.

## Personalizar
- Cambia las iniciales J ♡ K en `index.html` si lo deseas.
- Cambia los textos en `index.html`.
- Una vez confirmada la reserva, sustituye “El lugar será una sorpresa…” por el restaurante y la dirección. El botón de calendario crea un evento de 7:00 a 9:00 p. m. en Bogotá; ajusta la hora final si es necesario.
- El botón de la canción abre una búsqueda de YouTube, no reproduce audio automáticamente.

**Privacidad:** GitHub Pages es un sitio público. No subas fotos o información que no quieras compartir públicamente. Si compartes un álbum de Google Fotos, revisa los permisos del enlace.
